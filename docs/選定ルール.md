# 番組のルール：党首回（2026-11-19〜）

デイリー版は休止。**週1回、本編とショートの2本**を出す。先週（月〜日）の国会から作り、今週流す。
鮮度より「党首」を優先する（再生数と工数のため）。

## 対戦カード
- **自民党（高市早苗 内閣総理大臣）× どこかの政党の党首** の VS 構造を軸にする。
- 相手は野党に限らない。与党の日本維新の会も含む（与党 VS 与党もあり）。
- 党首＝代表・総裁・委員長・共同代表など、その党のトップ。党首・幹部の一覧は `docs/party_officers.json`。
- 場面は、党首が質問し高市総理が答えるやりとり（本会議の代表質問、予算委員会、党首討論、特別委員会など衆参すべての会議）。
- 先週に党首×高市総理の場面がなければ、`docs/leader_backlog.json` の「まだ使っていない党首×高市総理」の中で一番新しいものを使う。それもなければ、先週の幹部×高市総理（例：共産 小池晃 書記局長）。
- 先週に複数あれば：党首討論 ＞ 予算委員会 ＞ 本会議の代表質問 ＞ その他、同じなら知名度・話題性の高い党首。使わなかったものは backlog に入れる。

## タイトルとサムネイル（必須）
- タイトルとサムネイルの両方に、**政党名（特に「自民党」）と「高市」の名前**を入れる。相手の政党名と党首名も入れる。
  - 例：「【自民党・高市総理 vs 参政党・神谷代表】『配る政府』か『手取りを増やす』か｜参院予算委」
- サムネイルには**高市総理と相手の党首の顔**を入れる。顔は、その回で使う審議中継の映像から切り出した静止画を使う（ネットの写真は使わない）。候補は `thumbs/` に置く。
- 誇張・揶揄・事実でない言い回しはしない（「論破」「完敗」など不可）。字幕付き映像の揶揄的な転載は参議院が控えるよう求めている。

## 切り出し・台本（従来どおり）
- 質問1本＝2文以内（目安5〜15秒、長い1文はそのまま）。文の途中で切らない。答弁の理由は削らない。
- 台本：冒頭にカード紹介 → テーマごとに「党首の質問 → 高市総理の答弁」を短く往復 → 話し手が変わるたびに横塚（サッカー実況風）かナビ（用語・素朴な疑問・合いの手）→ 終盤に総括（その後どうなった？）。
- 図解は大きな字で1パネル3〜5行。
- ショートは1本（58秒以内）。質問と答弁の一番の見せ場を1往復。
- BGM：自民・公明＝ラリーガ／参政・れいわ（いのちの党）＝マンフト／立憲・共産・社民＝ブンデスリーガ／国民民主・維新・その他＝セリエA／総括＝ビューティフルゴール
- 引用元表示：「引用：参議院インターネット審議中継（YYYY年M月D日 会議名）」／衆議院は「引用：衆議院インターネット審議中継（…）」。

## 素材の取り方
- 参議院：ビデオライブラリ `detail.php?sid=<番号>` に「会議の経過」（高市内閣総理大臣の出席が書かれる）と発言者一覧（秒つき）。映像は mediasp プレーヤーの m3u8、字幕（WebVTT）も取れる。
- 衆議院：ビデオライブラリ `ex=VL&deli_id=<番号>`（`tools/discover_shugiin.py <out> <日付>`）。発言者一覧は質問者だけで答弁者は出ないので、総理の出席は字幕・文字起こし・報道で確かめる。
- 会議録API は約2週間遅れ。backlog の確認には使える。
