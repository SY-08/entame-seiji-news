# 切り出す発言の選び方（2026-11-18〜）

## 対象
- その日の**すべての会議**：衆議院・参議院の本会議、予算委員会、各委員会、特別委員会など。
- 衆議院：`live/<日付>/shugiin.json`（ビデオライブラリ。会議が終わって十数分後に載る。発言者一覧・会派・録画の秒つき）
- 参議院：`live/<日付>/sangiin/<会議>/transcripts/`（中継を収録しながら90秒ごとに文字起こし）。会議一覧は `live/<日付>/meetings_*.json`

## 質問側（議員）：各政党から1人ずつ
1. 党首（代表・総裁・委員長・共同代表など）
2. 幹部（幹事長・政調会長・国対委員長・代表代行・幹事長代行・総務会長・選対委員長・参院議員会長・書記局長など）
3. その他
- 同じ順位なら、知名度の高い人を優先（党の顔として報道に出る回数が多い人、閣僚・党首経験者など）。
- 党ごとの区分は `docs/party_officers.json` を使う。載っていない人・古い情報は、その日に党の公式「役員一覧」で確かめて更新する（確かめた日付と出典URLを書く）。
- 同じ政党の議員が複数の会議に出ていても、その日は1人だけ。

## 答弁側
- 内閣総理大臣 ＞ 大臣（副大臣・政務官を含む政務三役は大臣の次） ＞ 政府参考人
- 同じ質問に複数が答えていたら、この順で上の人の答弁を使う。

## speakers.json に必ず書くこと
- 各議員：氏名（正しい漢字）、会派、**区分（党首／幹部／その他）と役職名**、区分の出典、会議名、質問の開始・終了時刻、質問テーマ（1行）
- 答弁者：氏名と役職（政府参考人で氏名が確かめられないときは役職だけ）、区分（総理／大臣／政府参考人）

## 締め切り
- 制作側は毎日15時から GitHub を見に行く。**17時ごろまでに push**（19時チェック・20時公開）。
- 15時の時点で終わっていない会議は、その時点までに収録・文字起こしできた部分から選ぶ。

## 切り出し・台本のルール（制作側の指定）
- 質問・答弁それぞれ1〜2本／カード。1本は2文以内（目安5〜15秒）、文の途中で切らない、答弁の理由部分は削らない。
- cXX.json に話者名・会派・秒つき文字起こし。字幕は音声と照合して氏名・会派・数字を確定。
- 台本：冒頭にカード一覧 → カードごとに質問→答弁を短く往復 → 話し手が変わるたびに横塚（サッカー実況風）かナビ（用語・素朴な疑問・合いの手）→ 終盤に総括（その後どうなった？）。
- 図解は大きな字で1パネル3〜5行。
- ショート：前半戦＝質問側の発言だけ、後半戦＝答弁側の発言だけ。それぞれ合計30〜35秒。
- BGM：自民・公明＝ラリーガ／参政・れいわ＝マンフト／立憲・共産・社民＝ブンデスリーガ／国民民主・維新・その他＝セリエA／総括＝ビューティフルゴール
- 引用元表示：「引用：参議院インターネット審議中継（YYYY年M月D日 会議名）」／衆議院は「引用：衆議院インターネット審議中継（…）」
